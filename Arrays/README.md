# Array Problems — Easy LeetCode Solutions

This repository contains my solutions to array-based LeetCode problems explained in the easiest way possible.

The goal of this repo is not just to solve problems, but to understand **how to think**, **why the solution works**, and **how to solve it in a simple way**.

I created this while learning DSA from scratch and breaking each problem down into beginner-friendly steps.

---

## What This Repo Contains

This repo includes:

- Easy-to-understand LeetCode array solutions
- Beginner-friendly explanations
- Step-by-step thinking process
- Simple and clean code
- Notes on why the approach works
- Time and space complexity in easy words

Every solution is written in the simplest way possible so it is easy to learn, revise, and understand later.

---

## How I Solve Problems

For every problem, I try to solve it in the most beginner-friendly way possible.

My approach is simple:

1. Understand what the problem is asking
2. Break it into small steps
3. Find the easiest pattern
4. Write clean and simple code
5. Explain why it works
6. Add time and space complexity in easy words

The focus is not on writing clever code.

The focus is on writing code that is:
- easy to read
- easy to understand
- easy to remember
- easy to explain
