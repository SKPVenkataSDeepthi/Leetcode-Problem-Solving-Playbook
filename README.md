## 🧠 My Problem-Solving Framework

When I see a problem, my brain does this:

```text
1. Panic a little
2. Identify pattern (or pretend to)
3. Start brute force (because honesty > ego)
4. Optimize step by step
5. Realize edge case broke everything
6. Fix. Submit. Repeat.
```
